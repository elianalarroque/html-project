# HTML & CSS Project

¡Bienvenido a mi cápsula del tiempo! Este proyecto es un viaje nostálgico a la estética y2k de los años 2000 mezclado con algo de actualidad, desarrollado como parte de mi formación en el bootcamp de Software Developer para el módulo de **HTML y CSS**. 

**[Ver el proyecto en vivo aquí](https://elianalarroque.github.io/html-project/)**

---

## Sobre el Proyecto

El objetivo de este desarrollo fue recrear la experiencia visual de principios de milenio, integrando elementos icónicos como el **clásico MSN Messenger** y el **iPod classic**, mientras aplicaba los conceptos aprendidos en clase.

### Características principales:
* **MSN Login Experience:** Un modal funcional que simula el inicio de sesión del mítico mensajero, con cambio de estado de iconos mediante JavaScript.
* **Interactive iPod Playlist:** Sección dedicada a la música con una interfaz inspirada en los vectores clásicos de Apple, con una playlist embebida de Spotify.
* **Back to 2000s Quiz:** Un juego de preguntas interactivo para poner a prueba los conocimientos sobre la década.

---

## Tecnologías utilizadas

* **HTML5:** Estructura semántica de todas las secciones.
* **CSS3:** Layouts, manejo de fondos personalizados, fuentes retro y animaciones.
* **JavaScript:** Lógica del modal de login, validaciones simples, llamadas a API y dinamismo en el quiz.
* **Git & GitHub:** Control de versiones y despliegue mediante GitHub Pages.
